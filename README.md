# פוקימון חשבון ⚡

משחק תרגול חשבון בעברית לכיתה ב', לפי תכנית הלימודים במתמטיקה של משרד החינוך.
פותרים תרגילים בקרבות מול פוקימונים בר, מרוויחים פוקדולרים, תופסים פוקימונים ומפתחים אותם.

אתר סטטי בלבד: HTML, CSS ו-JavaScript רגיל. אין שרת, אין שלב בנייה.

> התמונות **לא** שמורות בפרויקט - הן נטענות בזמן המשחק מהמאגר הפתוח [PokeAPI](https://github.com/PokeAPI/sprites).
> בלי אינטרנט מוצג עיגול צבעוני עם שם הפוקימון, והמשחק ממשיך לעבוד.

## איך משחקים

- **באינטרנט:** דרך GitHub Pages (הקישור של הריפו).
- **במחשב:** לחיצה כפולה על **start-game.cmd** (צריך Python). נפתח חלון שחור (השרת הקטן) והדפדפן נפתח על
  `http://localhost:8124`. לסגירה - סוגרים את החלון השחור.

> אי אפשר לפתוח את `index.html` בלחיצה כפולה, כי המשחק בנוי ממודולים של JavaScript שדורשים שרת.

## מה יש במשחק

- **קרב** - 5 שאלות מול פוקימון בר. תשובה נכונה מחלישה אותו, ובסוף זורקים פוקדור ומנסים לתפוס.
  ככל שעונים נכון יותר - קל יותר לתפוס. טעות ראשונה = רמז, טעות שנייה = פתרון מלא בשלבים, והשאלה חוזרת בקרב הבא.
- **מפת המכונים** - כל נושא בתכנית הוא מכון. 3 כוכבים במכון = התג שלו 🏅.
- **פוקידקס** - האוסף. בוחרים פוקימון מלווה, והוא צובר ניסיון מכל תשובה נכונה ומתפתח ברמה מסוימת.
  חלק מהפוקימונים מתפתחים רק עם אבן התפתחות.
- **פוקימרט** - כדורים, אבני התפתחות, סוכריות נדירות וביצים שבוקע מהן פוקימון.
- **מתקפת ברק** - 60 שניות של עובדות חיבור וחיסור (ולוח הכפל, כשהנושא פתוח).
- **הקראה בקול** - כל שאלה מוקראת אוטומטית בעברית (אפשר לכבות במסך ההורים).

## מסך הורים

לחיצה ארוכה של 3 שניות על הכפתור "למבוגרים" במסך הבית. שם:

- **פותחים נושאים** לפי מה שכבר נלמד בכיתה. בתחילת השנה פתוחים רק: מספרים עד 1,000, זוגי ואי-זוגי,
  חיבור וחיסור, המספר החסר, אומדן והשוואה, ושאלות חיבור וחיסור.
- דיוק לפי נושא, נושאים שכדאי לתרגל, גיבוי, שחזור ואיפוס.

## מבנה הקבצים

```
index.html            המסכים
css/styles.css        עיצוב, כולל כללי RTL/LTR
js/main.js            הפעלה, ניווט, גיבוי ושחזור
js/storage.js         שמירה ב-localStorage, גרסאות ומיגרציה
js/topics.js          רשימת הנושאים (המכונים) לפי פרקי התכנית
js/questions.js       מנוע השאלות - גנרטורים + דוגמאות מתוך התכנית
js/qui.js             רכיבי הממשק של סוגי השאלות
js/progress.js        פוקדולרים, ניסיון, דרגות, תגים, רצף וסטטיסטיקה
js/pokedex.js         נתוני הפוקימונים: שמות, סוגים, נדירות והתפתחות
js/pokemon.js         האוסף: תפיסה, מלווה, רמות, התפתחות, ביצים
js/shop.js            הפוקימרט
js/art.js             תמונות וציורים (פוקימונים, כדורים, ביצים, קוביות, כסף)
js/battle.js          לולאת הקרב והתפיסה
js/map.js             מפת המכונים
js/lightning.js       מיני משחק "מתקפת ברק"
js/ui.js              מסכים, חלוניות, מקלדת מספרים, פוקידקס, פוקימרט ומסך הורים
tests/                בדיקות אוטומטיות
```

## בדיקות אוטומטיות

אם מותקן Node.js:

```
node tests/test-generators.mjs
node tests/test-modules.mjs
```

הבדיקות מוודאות שכל גנרטור מחזיר תשובה נכונה (בחישוב עצמאי) ובטווח המספרים של כיתה ב',
שלכל שאלה יש רמז ופתרון, שמנגנון התפיסה וההתפתחות עובד, ושהשמירה והמיגרציה תקינות.

## שמירת התקדמות

ההתקדמות נשמרת בדפדפן (localStorage) אחרי כל שאלה, בנפרד בכל מחשב ודפדפן.
כדי להעביר התקדמות בין מחשבים: במסך ההורים מורידים קובץ גיבוי, ובמחשב השני משחזרים ממנו.
